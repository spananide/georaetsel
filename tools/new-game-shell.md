# How a game page in this repo is built (read before writing a new game)

Every game lives in its own folder `<folder>/` and follows `flaggen/` exactly:

- `index.html` – copy `flaggen/index.html` as the shell and change only: `<title>`, description and og tags (url `https://geo.spanani.de/<folder>/`), the `<h1 class="wordmark">`, the tab labels (`#tab-daily` "Tagesrätsel", `#tab-practice` "Unbegrenzt"), the content of `<main>`, and the privacy dialog (use the privacy paragraphs of `rangliste/index.html`, they mention the leaderboard). Keep: back link `../`, `#clock`, theme button, tabs, footer (Datenschutz, Impressum), `#toast`, the service worker registration line. Links: `../common.css` then `style.css`.
- `style.css` – only the game-specific styles. Use the CSS variables of `common.css` (`--page --sea --line --ink --soft --panel --warn --tief --huegel --hoch` and their `*-ink` pairs) so dark and light theme both work; reuse `.btn .btn-primary .btn-secondary .tabs .tab-btn .end-card .toast`. Mobile first (320px wide, no horizontal scroll), touch targets at least 44px, visible focus ring, `prefers-reduced-motion` respected. Look: atlas/sea palette, Barlow Condensed headings (already loaded by common.css). No emoji decoration in the UI except where the game needs them (share text).
- `logic.js` – pure functions, no DOM, no `window`/`localStorage` access, importable in Node. Exports `newRound(seed)` (a plain JSON-serialisable object that includes `seed`, `state`, and later `ms`), the move functions, `shareText(round, label, url)`. Daily rounds are deterministic from `seed` (`dailySeed(new Date())` from `../georaetsel/game.js`, a number like 20261110; `mulberry32` is exported there too).
- `app.js` – DOM + persistence. Copy the structure of `flaggen/app.js`: `mode` is 'daily' or 'practice'; the daily round is stored with `writeStorage('<key>.daily.<seed>', round)` (and loaded with `readStorage`), the practice round is kept in memory with a random seed; `startClock({getRound, isOver, save})` for the stopwatch (it adds `round.ms`); `withTime(shareText(...), round.ms)` + `shareText` from common.js for the share button; `initPrivacy()`; theme toggle; midnight rollover check like flaggen does (new day while the tab is open); the end view shows the result and a share button; practice has a "Neue Runde" button.
- **Leaderboard**: in `render()` call `reportRound('<id>', round, mode)` (import it from `../common.js`) as the first line, exactly as the other games. In `common.js` add the game to `GAME_INFO` (`{ name, unit }`) and a `case '<id>'` to `summarize(game, round)` returning `{ over, tries, won }`; do not change anything else in common.js. The localStorage key prefix must equal the game id (`<id>.daily.<seed>`), the leaderboard page backfills from `GAME_INFO` automatically.
- `test.mjs` – plain `node:assert` script run from inside the folder with `node test.mjs`, imports `./logic.js` only, prints `alles ok` at the end. Cover determinism per seed, every move function, win/lose transitions, `shareText`.
- Language: German UI text, English code comments. Style: 2-space indent, single quotes, semicolons, ES modules, no dependencies, no build step.
- Do not touch: the root `index.html` (hub), `sw.js`, other games, `worker/`.
