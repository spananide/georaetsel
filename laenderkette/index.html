Datenschutz

Dieses Spiel setzt keine Cookies, nutzt kein Tracking und lädt nichts von fremden Diensten nach.

Spielstand, Statistik und dein Farbschema liegen in deinem Browser (localStorage). Wenn du in der Rangliste oder in Tiefsee einen Namen eingibst, werden dein Name, das Datum, das Spiel, dein Ergebnis (Versuche, Zeit) und in Tiefsee deine Antworten an unseren Server (Cloudflare, USA) gesendet und sind für alle in der Rangliste sichtbar. Wähle keinen echten Namen, wenn du das nicht willst. Browserdaten kannst du jederzeit über deine Browsereinstellungen löschen; einen Namen samt Ergebnissen löschen wir auf Anfrage (Kontakt: siehe Impressum).

Die Seite wird von GitHub Pages ausgeliefert (GitHub Inc., USA). Dabei verarbeitet GitHub technisch nötige Zugriffsdaten wie deine IP-Adresse.
